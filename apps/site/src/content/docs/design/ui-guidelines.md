本规范适用于桌面端所有页面、弹窗和交互状态。新增或修改 UI 时必须遵守；若实现与规范冲突，应先更新规范并说明原因。

## 1. 品牌主题：双语义色

MagneticTape 保留绿色作为本地、安全、录制的主色，同时引入 Iris（紫）作为 **AI 能力**的第二语义色。颜色表达的是“能力域”，不等于允许随意使用彩色：

- **绿色**：本地、录制、安全、成功，以及所有非 AI 的主操作。
- **Iris（紫）**：AI 同传、AI 助手、实时字幕、转写、翻译、AI 纪要。
- 页面主按钮、导航选中、录音控制不得使用 Iris；AI 入口也不得使用绿色以外的装饰色混搭。

| 令牌 | 色值 | 用途 |
|---|---|---|
| `--ui-primary` | `#128456` | 开始录音、暂停态、进度、本地操作 |
| `--ui-primary-hover` | `#0C6B44` | 悬停、按下 |
| `--ui-primary-soft` | `#E6F6EF` | 浅色按钮、图标底座、活动背景 |
| `--ui-iris` | `#6C5CE7` | AI 主操作：转写、生成纪要、发送 |
| `--ui-iris-hover` | `#5A4BD1` | AI 操作悬停/按下 |
| `--ui-iris-soft` | `#EFEBFE` | AI 图标底座、AI 次级按钮、译文底 |
| `--ui-iris-ink` | `#4E3FC8` | AI 浅底上的文字 |
| `--ui-ink` | `#232338` | 标题和主要文字 |
| `--ui-muted` | `#646A7E` | 辅助说明和次要信息 |
| `--ui-line` | `rgba(84, 90, 126, .12)` | 卡片与控件边界 |

品牌色必须通过 CSS 自定义属性引用。禁止在组件样式中新增重复的品牌色十六进制值；透明效果使用对应的 `rgba()` 令牌。

## 2. 语义色

- 红色：录音警示、错误、删除等危险操作。
- 橙色：暂停、需要用户关注但不阻断流程的警告。
- 绿色：成功、安全、活动状态和所有本地交互。
- Iris：AI 能力的入口与结果。
- 灰色：禁用、待机和辅助信息。
- 蓝色：仅用于说话人标识等需要额外区分的粉彩标签，不得用于主操作。

颜色不能作为唯一状态提示；必须同时提供文字、图标或形状变化。

## 3. 图标

- 统一使用项目已引入的 Lucide 图标库，不新增风格不一致的手绘 SVG。
- 常规图标使用 `16–20 px`，主视觉图标使用 `20–28 px`，线宽保持 Lucide 默认视觉风格。
- 带文字的按钮使用“图标在左、文字在右”；纯图标按钮必须提供 `title` 和可访问名称。
- 同一操作在不同页面使用相同图标，不使用图标代替难以理解的业务文案。

## 4. 材质、组件与层级

- 视觉层级遵循 v7 的三层结构：极光画布 → 玻璃外壳 → 实色内容。玻璃只用于两块主面板，内层控件不得叠加 `backdrop-filter`。
- 主面板圆角 `26px`，状态卡/弹窗区块 `20px`，功能卡片 `16px`，按钮与输入框 `12px`，状态标签使用胶囊。
- 卡片优先使用“半实色底 + 柔和阴影 + 内高光”建立层级；边框只作为辅助。禁止多层高强度阴影。
- 主按钮：绿色实底、白色文字；一个操作区域原则上只出现一个主按钮。AI 主操作使用 Iris 实底。
- 次按钮：浅绿底或中性灰底；危险按钮使用浅红底或红色文字。
- 输入框、下拉、文本域：实色/半实色底 + `--ui-line` 描边，聚焦时使用对应语义色的 3px 焦点环。
- 聚焦环：绿色控件 `rgba(18,132,86,.28)`；Iris 控件 `rgba(108,92,231,.30)`；键盘操作必须可见。
- 文字不得直接落在低透明度玻璃上：需要时在文字区域增加 ≥ 85% 白的 scrim。

## 5. 录音状态

- 待机：中性背景配绿色主操作。
- 录音中：绿色为主要活动色，红色只用于“录音中”警示点或停止操作。
- 暂停：降低波形与活动区域饱和度，保留清晰的继续入口。
- 完成：使用绿色成功状态，导出仍为绿色主操作。
- 错误：使用红色提示，同时保留可恢复操作。
- 状态必须同时通过文案与颜色表达。

## 6. 验收检查

提交 UI 变更前至少确认：

1. 本地/录制/主操作使用绿色令牌；AI 能力使用 Iris 令牌；两者不混用。
2. 页面不存在无 AI 语义的紫色品牌元素，也不存在无本地语义的绿色 AI 元素。
3. 图标来自 Lucide，尺寸和排列一致。
4. 键盘焦点清晰，文字与背景满足 WCAG AA 对比度；微标签不小于 `10.5px`。
5. `backdrop-filter` 只出现在主面板与弹窗；关闭模糊后层级仍可辨认。
6. `npm run build` 和现有测试通过，录音状态与事件选择器未被破坏。
