## 1. 目标与边界

本规格把现有“录音区 + 内容区”的双栏页面升级成截图中的三栏 AI 工作台：

1. 顶部品牌与全局导航。
2. 左侧录音控制中心（场景、配置、录音状态）。
3. 中间实时内容工作区（五种视图）。
4. 右侧 AI 洞察与 AI 对话。
5. 底部全局播放器。

本版优先完成**布局、信息层级与可交互骨架**。真实录音、实时字幕、转写、翻译、纪要、导出继续复用现有 Tauri 命令；AI 洞察在没有独立分析接口时使用本地可解释的占位/摘要，不伪造会议结论。

### 1.1 设计原则

- **录音是入口**：左栏的计时、波形、暂停/结束始终是视觉重心。
- **内容优先**：中间栏占据最大宽度，AI 洞察不得挤压实时转录阅读区。
- **能力分色**：绿色只表达本地、录制、成功；Iris 只表达 AI 能力；红色只表达错误；琥珀只表达暂停。
- **不逐像素复制参考图**：采用参考图的空间关系、卡片节奏与深浅层级，文案、图标与功能必须服务 MagneticTape。

### 1.2 不在本版范围

- 说话人身份编辑、说话人分离、跨录音知识图谱。
- AI 洞察的专用流式分析模型与结构化协议。
- 任务负责人/截止时间的自动抽取与确认流。
- 拖拽调整栏宽、栏折叠动画、完整移动端布局。

以上能力保留入口或占位，在后续迭代补全。

## 2. 整体布局

### 2.1 参考尺寸

以 1536 × 1024 视口为基准（平台窗口建议默认 1440 × 960，最小 960 × 640）：

| 区域 | 尺寸/规则 |
|---|---|
| 页面外边距 | 16 px |
| 顶部栏 | 高 72 px，左右 24 px 内边距 |
| 主工作区 | 顶部栏下方，底部播放器上方 |
| 列间距 | 16 px |
| 左栏 | 396 px（`clamp(340px, 27vw, 412px)`） |
| 中栏 | 自适应，最小 480 px |
| 右栏 | 388 px（`clamp(320px, 25vw, 400px)`） |
| 底部播放器 | 高 56 px，与主工作区间距 12 px |
| 主面板圆角 | 16 px |
| 内层卡片圆角 | 12 px |
| 主面板边框 | 1 px `rgba(31, 41, 55, .07)` |
| 主面板阴影 | `0 12px 32px rgba(31, 41, 55, .05)` |

页面使用 `100dvh` 锁定高度，主工作区内部面板各自滚动，不出现整页滚动条。

### 2.3 响应式规则

| 宽度 | 布局 |
|---|---|
| ≥ 1360 px | 三栏常驻，按 2.1 比例 |
| 1100–1359 px | 三栏常驻，左栏收窄至 340 px，右栏收窄至 320 px |
| 960–1099 px | 保留左 + 中两栏；右栏变为可呼出的侧滑面板，顶部“AI 洞察”按钮打开 |
| < 960 px | 允许窗口最小宽度阻止继续缩小；内容区横向滚动兜底 |

高度不足 760 px 时，左栏配置区允许内部滚动；录音控制区仍吸底可见。底部播放器始终保留。

## 3. 顶部栏

- 左侧品牌：44 px 绿色圆角方块 + Lucide `Mic` 图标；主标题“AI 录音工作台”22 px/700；副标题“录音 · 转录 · AI 洞察 · 知识沉淀”11 px。
- 右侧导航：历史记录、知识库、设置，均为图标 + 文案的幽灵按钮；悬停为浅灰底。
- 历史记录打开现有录音库弹窗。
- 知识库打开 V1.0 占位弹窗，明确“跨录音知识检索将在后续版本提供”。
- 设置打开设置入口弹窗，聚合 AI 服务、转写服务与本地数据入口。
- 顶部栏不显示录音状态；录音状态属于左栏与底部播放器。

## 4. 左栏：录音控制中心

### 4.1 面板标题

- 32 px 圆形数字徽标“1”，背景浅绿，文字深绿。
- 标题“录音控制”15 px/650。
- 右侧为收起按钮；V1.0 只做禁用/提示，不实现折叠。

### 4.2 录音场景

- 标题“录音场景”12 px；右侧帮助图标 + 展开箭头。
- 六宫格按钮：会议、学习、灵感、访谈、通话、其他。
- 每格高 68 px，图标 18 px 在上、名称 11 px 在下；默认 3 列 × 2 行。
- 选中态：1 px 绿色描边、极浅绿底、图标/文字变深绿，并保留 `aria-pressed="true"`。
- 录音开始后场景切换禁用，`title` 说明“录音中不可切换场景”。
- 场景选择写入 `localStorage`（键 `magnetic-tape.scene`），刷新后保留。

### 4.3 配置分组

三组均使用折叠卡：

| 分组 | 摘要行 | 展开内容 |
|---|---|---|
| 语言与翻译 | 图标 + “自动识别 · 不翻译” | 转写语言、AI 同传目标语言 |
| 音频设备 | 图标 + 当前设备摘要 | 麦克风、系统输出、重新检测 |
| AI 模型 | 图标 + Provider / 模型 | AI 服务配置、实时字幕开关 |

- 摘要行高 44 px；展开后内边距 10 px。
- 同一时间允许多组展开；默认只展开“语言与翻译”，录音开始后全部收起。
- 选择变更继续调用现有 `persistSettings`。
- “AI 模型”右侧显示绿色“已配置”或琥珀“未配置”状态点。

### 4.4 录音状态卡

- 浅绿渐变卡片，圆角 14 px，内边距 14 px。
- 顶部状态胶囊：录音中为红色圆点 + “正在录音”；暂停为琥珀；待机为灰色。
- 波形：48 根绿色圆角竖条，高度由实时音频电平驱动；暂停时降饱和并停止动画。
- 计时：`32 px/650`，等宽数字，格式 `MM:SS` 或 `HH:MM:SS`。
- 状态说明：如“正在录音 · 本地安全保存”。
- 主操作行：
  - 待机：绿色“开始录音”按钮，占满整行。
  - 录音/暂停：两个并排按钮“暂停/继续”和“结束”；宽度各 50%。
- 录音卡下方是双通道电平，每行包含图标、名称、进度条；“正常/无声/异常”通过文字和数值说明。
- 设备异常提示紧邻录音卡显示，不覆盖主操作。

## 5. 中栏：实时内容

### 5.1 面板标题

- 数字徽标“2” + “实时内容”。
- 右侧：`LIVE` 胶囊（录音中为浅红点+红字，待机为灰）、全屏/展开图标按钮。
- V1.0 全屏按钮切换中栏为“专注阅读”类（隐藏左右栏），按 `Esc` 退出。

### 5.2 视图 Tab

五个 Tab：转录、翻译、AI 分析、任务、AI 对话。

- 选中态：浅绿底、绿色边框、深绿文字；图标 15 px。
- 未选中：透明底、灰色文字；悬停浅灰底。
- Tab 使用 `role="tab"`、`aria-selected`，面板使用 `role="tabpanel"`。
- Tab 切换不重置录音状态、滚动位置与对话历史。
- 默认打开“转录”。

### 5.3 转录视图

- 顶部为说话人条目列表。
- 单条结构：
  - 第一行：发言人彩色圆点 + “发言人 A” + 时间戳 + 右侧“已识别”胶囊 + 播放圆钮。
  - 第二行：13.5 px/1.75 正文，最多自然换行。
  - 条目之间用 12 px 间距分隔，不再使用重边框卡片。
- 发言人颜色循环：绿、蓝、紫、琥珀，颜色只用于圆点与浅底标签。
- 时间戳可点击跳转到音频位置，并给该条添加 `active` 高亮。
- 识别中占位：居中浅灰胶囊 + 旋转加载点 + “正在识别下一段语音…”。
- 空态：居中的磨砂图标砖 + “开始录音后，实时转写会显示在这里”。
- 实时字幕到达时：
  - 用户位于底部则自动跟随。
  - 用户上滚超过 24 px 后暂停跟随，显示“回到最新内容”浮按钮。
  - 新片段不得强制改变当前阅读位置。
- 底部工具条固定在中栏底部：编辑、标记重点、复制、跳转音频、更多。
  - 无转写时禁用。
  - “编辑”进入选中片段的行内编辑；V1.0 至少支持修改最后一段并标记“已编辑”。
  - “复制”复制当前可见转写全文。
  - “跳转音频”在完成态调用全局播放器定位。
  - “更多”打开菜单：导出会议资料、删除音频（仅在完成态可用）。

### 5.4 翻译视图

- 显示原文 / 译文上下对照；译文使用 Iris 左边线与浅紫底。
- 未生成译文时展示空态和“完成转写后生成翻译”说明。
- 实时同传结果按段渲染，失败不清空原文。

### 5.5 AI 分析视图

- 以卡片展示：当前主题、关键观点、待办事项、会议摘要。
- 完成态“生成纪要”复用现有 `summarize_session`，结果写入 `.meeting-notes` 并同步右栏摘要。
- 记录笔记编辑区与保存按钮保留在完成态。
- 未接入独立 AI 分析接口时，卡片明确标注“等待转写”或“AI 生成 · 待确认”。

### 5.6 任务视图

- 空态说明“任务会从转写中提取，确认后才进入正式记录”。
- 已完成且有笔记时，解析 Markdown 复选框行（`- [ ]`、`- [x]`）形成只读任务列表。
- 不伪造负责人和截止时间。

### 5.7 AI 对话视图

- 与右栏 AI 对话共享同一段聊天记录 DOM 数据（切换 Tab 不丢消息）。
- 消息结构：用户气泡靠右（浅绿）；AI 回答靠左（白底 + Iris 标识）。
- 回答必须标注“基于当前录音内容”，并在失败时显示可读错误。
- 输入框占位“输入你的问题…”，回车发送，`Shift+Enter` 换行。

## 6. 右栏：AI 洞察与 AI 对话

### 6.1 AI 洞察面板

- 标题：“3 AI 洞察”，右侧 Iris 星标。
- 卡片顺序：当前主题 → 关键观点 → 待办事项 → 会议摘要。
- 卡片样式：浅色底（主题浅绿、观点白、待办浅绿、摘要浅灰），12 px 圆角，10–12 px 内边距。
- 当前主题：显示录音标题、实时主题或“等待开始录音”。
- 关键观点：最多 3 条，每条附来源时间；无数据时说明“转写后自动提炼”。
- 待办事项：显示数量胶囊；从笔记解析；无数据时“暂未识别到待办”。
- 会议摘要：完成态显示笔记摘要或生成按钮；未完成时显示“录音结束后生成”；超过 4 行时“展开”。
- 面板内部独立滚动。

### 6.2 AI 对话面板

- 标题“4 AI 对话”，右侧刷新/清空按钮。
- 默认展示一条建议提问气泡。
- 输入区：圆角输入框 + 48 px 绿色发送按钮（`Send` 图标）。
- 无已配置 AI Key 时，发送后显示“请先在设置中配置 AI 服务”，不阻塞录音。
- 聊天请求复用 `generate_ai`，附带当前标题与最近 20 段转写作为上下文。

## 7. 底部播放器

- 全宽、高 56 px 的白底卡片，圆角 14 px。
- 左侧圆形播放按钮（34 px，绿色软底），播放中切换为暂停图标。
- 时间显示 `当前 / 总时长`，等宽数字。
- 中间为细进度条，绿色已播放段、灰色轨道。
- 右侧：倍速选择（0.75×–2×）、音量图标 + 音量条、全屏按钮。
- 完成态接入 `TimelinePlayer`，支持拖动进度、倍速和字幕跳转。
- 录音中显示实时累计时长；无音频时按钮禁用并给出可读提示。
- 播放器不随中间栏滚动。

## 8. 状态映射

| 状态 | 左栏 | 中栏 | 右栏 | 播放器 |
|---|---|---|---|---|
| Idle | 场景可切换、配置可用、开始按钮 | 空态 + Tabs | 提示开始录音 | 禁用 |
| Recording | 场景锁定、配置收起、波形活动 | 实时转写 / 识别占位 | 更新主题与关键观点 | 显示累计时长 |
| Paused | 波形静止、状态琥珀 | 保留内容、显示已暂停 | 不清空 | 显示累计时长 |
| Stopping | 按钮禁用、保存提示 | 保留内容 | 保留内容 | 保留 |
| Finished | 显示“录音已保存”、录音按钮变为“开始新录音” | 转写工作台 / 摘要 / 任务 | 摘要与待办 | 真实时间轴可用 |
| Error | 错误条 + 可恢复操作 | 保留已有内容 | 保留已有内容 | 保留 |

## 9. 数据与组件边界

- 静态骨架由 `renderApp()` 一次性渲染；状态变化由 `applyView()` 更新，避免整页重绘丢失滚动位置。
- 录音状态、计时、电平继续由 `main.ts` 的页面控制器管理。
- `renderTranscript()` 只负责片段 DOM；时间戳跳转仍走 `seekFromTranscript()`。
- AI 洞察更新函数接收当前转写片段和笔记，不直接调用 Tauri。
- 聊天请求由页面控制器发起，UI 只渲染消息。
- 不新增 React 或状态库，保持 Vanilla TypeScript。

## 10. 可访问性

- 所有按钮为原生 `button`；图标按钮必须有 `aria-label` 和 `title`。
- Tabs 支持左右方向键切换、Home/End 跳转。
- 录音状态通过 `aria-live="polite"` 播报；计时器不做每秒播报。
- AI 分析、任务等非事实内容标注“AI 生成 · 待确认”。
- 焦点环统一 3 px；颜色不是唯一状态信号。
- 尊重 `prefers-reduced-motion`；暂停/减少动态效果时波形静止。

## 11. 验收标准

1. 1440 × 960 下呈现三栏；1536 × 1024 下空间比例与参考图一致。
2. 1220 × 900 下三栏压缩但不重叠；960 × 640 下右栏可呼出，无整页横向滚动。
3. 左栏场景选中、折叠组、设备摘要和录音控制均可用键盘操作。
4. 录音开始后实时字幕进入中栏，时间戳和播放按钮可定位。
5. 五个 Tab 切换不丢失录音状态；空态、加载态、错误态文案明确。
6. 右栏洞察与聊天在无数据时不伪造内容；配置 AI 后聊天可返回结果。
7. 完成录音后播放器可播放、拖动与切换倍速。
8. `npm run build`、`npm test`、`npm run test:e2e` 通过。
