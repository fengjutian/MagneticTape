## 三步开始

1. **安装**：从 [Releases](https://github.com/fengjutian/MagneticTape/releases/latest) 下载 `MagneticTape_<版本>_x64-setup.exe`。
2. **选设备**：在录音页确认麦克风与系统输出设备，实时电平会随你说话跳动。
3. **开录**：点击开始录音，工作台右侧实时出现字幕与译文，结束后可转写、导出。

细节见 [安装](/start/install/) 与 [快速开始](/start/quick-start/)。

## 下载

当前处于早期开发阶段：双路录音、分片恢复、转写、实时字幕、设备自动重连与安装包都已可用，但**安装包未做代码签名**，Windows SmartScreen 会提示「未知发布者」，选择「仍要运行」即可；**自动更新也尚未接入**，新版本请手动下载。

:::caution
请不要把它当作重要会议的唯一录音工具。首次使用前请用一段短录音完整验证一遍你的设备组合。
:::

## 本地优先

录音、转写与笔记默认全部保存在本机；只有在你自己配置了 API Key 并显式触发云端能力（云端转写 / 翻译 / 纪要 / 对话）时，数据才会离开这台电脑。详见 [数据与隐私](/guide/privacy/)。
