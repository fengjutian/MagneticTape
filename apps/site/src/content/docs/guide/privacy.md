## 默认全部留在本机

MagneticTape 是本地优先的工具。录音、转写、说话人标签、会议笔记和设置默认都保存在你这台电脑上，不会上传。

只有在你**自己配置了 API Key 并显式触发**云端能力时，数据才会离开本机：

| 触发动作 | 离开本机的内容 | 发往哪里 |
|---|---|---|
| 选择云端 ASR（MiniMax / SiliconFlow / OpenAI Realtime）并开始转写 | 混音后降采样到 16 kHz 的音频 | 你选的服务商 |
| 开启 AI 同传 | 新增实时字幕的文本 | 你配置的 AI 服务商（MiniMax / DeepSeek） |
| 点「AI 翻译」或「AI 生成纪要」 | 转写文本 / 笔记正文 | 同上 |
| 使用 AI 对话 | 录音标题、最近 20 段转写片段、你的问题 | 同上 |

不配置任何 API Key 时，应用不会发起任何内容上传请求。本地 Whisper 推理全程离线，只有下载引擎和模型那一步需要联网。

## 数据保存在哪

| 内容 | 位置 |
|---|---|
| 录音分片、转写、笔记、恢复清单 | 应用数据目录下的 `recordings/<会话编号>/` |
| 本地 Whisper 引擎与模型 | 应用数据目录下的 `local-whisper/` |
| 本地流式引擎与模型 | 应用数据目录下的 `sherpa/` |
| 设置与界面偏好 | 应用数据目录下的 `settings.json` |
| 日志与崩溃报告 | 应用数据目录下的 `logs/` |
| 导出资料 | `文档/MagneticTape/<标题>-<会话编号>/` |

模型和引擎不在安装目录里，卸载应用不会连带删除你已下载的模型。

## 密钥怎么存

AI 服务商和云端 ASR 的 API Key 都保存在 **Windows 凭据管理器**里，不是明文文件，也不写进 `settings.json`。应用只把密钥发给你选定的那一家服务商。

- 「设置 → AI 服务」里的「清除密钥」会删除凭据条目。
- 「配置转写服务」里选「本地 Whisper」时，接口地址、模型名和 API Key 输入框会隐藏，本地转写完全不碰凭据管理器。

## 日志与诊断

日志在应用数据目录的 `logs/` 下：

- 滚动日志 `app.log`，单文件上限 10 MB，最多保留 5 份，只保留最近 7 天。
- 崩溃时额外写一份 `crash-<时间戳>.log`，包含崩溃信息和回溯。

「设置 → 录音资料库 → 导出诊断包」会打一个 zip 到导出目录，里面只有 `system.txt`（系统摘要）和日志/崩溃文件。**不含音频、不含密钥、不含转写正文。** 反馈问题时把这个包发出去即可。

## 目前还没做的

- **远程崩溃上报**：尚未实现。崩溃报告只写在本机，需要你主动导出诊断包才会离开电脑。
- **遥测**：没有任何后台统计或使用数据上报。
- **跨设备同步与账号**：不做。录音只在你自己的机器上。

## 你可以自己控制的部分

- 删音频：完成页「更多 → 删除音频」，转写和笔记保留。
- 删整条会话：历史库里的删除按钮，会移入 Windows 回收站，可还原。
- 清历史音频：按 30/90/180 天或 5/10/20 GB 上限清理，转写保留。
- 卸载后手动清理：卸载不会删数据目录，需要的话自己删。
