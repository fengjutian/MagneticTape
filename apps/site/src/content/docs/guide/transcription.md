字幕分两条链路：**录音时实时出字**（本地流式引擎），和**录后一次性转写**（本地 Whisper 或云端 ASR）。两者互相独立，实时字幕出错不影响录音。

## 实时字幕：默认走本地流式引擎

开启「AI 配置 → 实时字幕」后，应用优先使用本地 sherpa-onnx 流式识别：完全离线，约 1 秒出字，首字通常 0.3–0.5 秒，一句话在停顿约 0.8 秒后定稿。

第一次使用需要先在「设置 → 转写服务」里下载组件：

| 组件 | 大小 | 作用 |
|---|---|---|
| 流式引擎 | 24 MB | sherpa-onnx 运行库 |
| 中文流式模型 | 74 MB | 流式 ASR 模型（zh-14m） |
| 声纹模型 | 28 MB | 区分不同发言人（可选） |
| 分离模型 | 7 MB | 录后离线说话人分离（可选） |

引擎或模型没装、加载失败时，应用**自动回退**到原来的 5 秒分片轮询，录音完全不受影响。字幕区会提示「本地流式引擎未就绪，将按当前转写服务生成字幕」。

实时字幕是增量结果，最终以停止后生成的完整转写为准。

## 录后转写

在完成页选好服务商，点「开始转写」。

**本地 Whisper（离线）** 是默认选项：

- 引擎与 GGML 模型按需下载，下载后做 SHA-256 校验，校验不过的文件会被删掉并报错。
- 完全在本机跑，不需要 API Key，也不需要网络。
- 可选模型：`Tiny（实时字幕）`、`Base（快）`、`Small（推荐）`、`Large v3 Turbo（高质量·量化）`。默认 `small`。
- 应用会通过 `nvidia-smi` 自动探测 NVIDIA GPU；装了 CUDA 引擎就优先用它，否则回退 CPU 引擎。
- 「删除模型」只删当前模型文件，引擎和其余模型不受影响。

**云端服务**（可选）：`MiniMax（分片）`、`SiliconFlow（分片）`、`OpenAI Realtime（流式）`。选云端时，混音降采样到 16 kHz 的音频会上传给你选的服务商，API Key 同样保存在 Windows 凭据管理器里。选 `本地 Whisper` 时这些输入框会隐藏。

转写按音频分段推进，状态栏显示「正在转写 n/m 段」，随时可以点「取消」；取消不会留下半成品转写。部分段落失败时仍会返回已成功的结果。

## 热词

「转写服务」对话框里有一个「热词 / 提示词」输入框，最多 512 个字符。填上专有名词、产品名、参会人姓名（用逗号或顿号分隔），能明显提高术语识别率。本地 Whisper 会把它作为初始提示词传给引擎。

## 说话人区分

- 装了声纹模型时，本地流式引擎会在线聚类，字幕直接显示「发言人 A / 发言人 B …」。
- 没装声纹模型时只显示「发言人」，不按行号乱编号。
- 录后转写如果装了分离模型，会用 pyannote 离线重跑全量并覆盖在线标签；没装则保留在线标签。
- 点击发言人名字可以重命名，名字按会话保存在本地。
- 已知限制：两人同时说话时区分不可靠；单次离线分离上限 2 小时，更长的录音保留在线标签。
