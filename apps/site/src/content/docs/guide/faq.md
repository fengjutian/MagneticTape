## 安装与运行

**提示「未知发布者」能装吗？**

能。安装包**未做代码签名**，SmartScreen 一定弹这个提示，点「更多信息」→「仍要运行」即可，详见[安装](/start/install/)。

**会自动更新吗？**

不会。自动更新**尚未接入**，新版本手动下载覆盖安装，录音数据与设置不会丢。目前只支持 Windows 10 / 11（x64），macOS 与 Linux 支持还在路线图里。项目是 MIT License 开源，可以商用。

## 录音相关

**录音中途崩溃了怎么办？**

重新打开应用，它会扫描未正常结束的会话并自动恢复，完成页显示「已恢复上次录音」；恢复不了的标为「意外中断」。录音按每 5 秒一个独立可解码分片落盘，配合只增不改的 checkpoint 恢复。

**系统声音没录到？**

检查「音频配置」里选的系统输出设备是不是正在出声的那个输出端（外放、耳机、HDMI 常是不同设备），选错就录不到。

**设备掉线会断录音吗？**

不会。设备掉线、休眠唤醒或音频服务重启后会自动重建采集流，页面提示「正在自动重连…」。

## 字幕与转写

**实时字幕不出字？**

本地流式引擎或中文流式模型没装时，字幕区会提示「本地流式引擎未就绪」。到「设置 → 转写服务」下载流式引擎（24 MB）和中文流式模型（74 MB）即可。引擎加载失败时会**自动回退**到 5 秒分片轮询，录音不受影响，只是出字慢一些。

**实时字幕和最终转写对不上？**

实时字幕是增量结果，最终以停止后的完整转写为准。边界处偶尔断词或重复是已知问题。

**本地转写需要 API Key 吗？**

不需要，本地 Whisper 完全离线运行。默认 `Small（推荐）`约 488 MB，低配 CPU 可换 `Base（快）`，追求质量可用 `Large v3 Turbo`。GPU 通过 `nvidia-smi` 自动探测，需先下载 CUDA 引擎（约 272 MB）才会走 GPU，否则回退 CPU；CUDA 路径尚未完成真机验证。

**说话人分得不准？**

已知限制：两人**同时说话**时在线声纹不可靠；真实双人中文会议尚未按 85% 验收线验证；远场混响更难；离线分离单次上限 2 小时；没装声纹模型时只显示「发言人」，不会乱编号 A/B。

## AI 能力

**AI 同传翻译失败会丢内容吗？**

不会。翻译失败不影响录音和 ASR，字幕区提示「AI 同传将在稍后重试」，稍后自动接着翻。

**长会议纪要会被截断吗？**

不会。纪要采用分片提取 + 归并（map-reduce），先分段提炼要点再合并，不受单次输入或输出上限限制。

**AI 生成的内容能直接当会议记录吗？**

不能直接当定稿。AI 内容默认标记「待确认」，在复盘页逐条确认、编辑或忽略后才进入正式记录。AI 对话提问时只带上录音标题和最近 20 段转写片段作为上下文。

## 导出与存储

**导出到哪里？**

`文档/MagneticTape/<标题>-<会话编号>/`，含 `meeting.md`、`transcript.txt` / `.srt` / `.vtt`、`audio.wav`（双轨混音的 48 kHz 单声道 WAV）、`notes.md`、`session.json`，译文另存为 `translation-<语言>.md`。音频已删除时会跳过 `audio.wav`。

**磁盘快满了怎么办？**

「设置 → 录音资料库」里可按 30/90/180 天或 5/10/20 GB 上限清理音频，转写和笔记保留。想自动清理就把「自动清理」和「存储上限」设好，**下次启动**生效。

**音频删了还能看转写吗？**

能。历史库里这条会话仍在，标为「仅转写」，可继续查看和导出，只是不能回放。历史库里的删除按钮会把会话**移入 Windows 回收站**可以还原。

## 已知限制与未完成项

- 安装包未签名，自动更新未接入；远程崩溃上报未实现，崩溃报告只写本机，需手动导出诊断包。
- 只支持 Windows，不支持 macOS 与 Linux。
- 说话人分离精度未按 85% 验收线验证，重叠说话场景不可靠。
- 知识库（跨录音检索、主题关联、AI 问答）界面已占位，尚未上线。
- 历史库只能按标题和会话编号搜索；尚未提供 PDF / DOCX 导出与复制纪要。
- 尚无系统托盘、单实例与系统级全局快捷键，录音中关闭窗口没有二次确认。
- 采集增强（增益、降噪、回声消除、只录指定应用）未实现。
