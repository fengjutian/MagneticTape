## 一键导出

录音结束后的完成页点「导出资料」，复盘页点「导出」。导出会生成一个独立目录：

```text
文档/MagneticTape/<标题>-<会话编号>/
```

导出完成后应用会直接打开这个目录。目录里的文件：

| 文件 | 内容 |
|---|---|
| `meeting.md` | 标题、时长、转写与会议笔记拼成的一份 Markdown |
| `transcript.txt` | 纯文本转写，每行带时间戳和说话人 |
| `transcript.srt` / `transcript.vtt` | 带时间戳的字幕，可直接挂到播放器上 |
| `audio.wav` | 双轨混音后的 48 kHz 单声道 WAV |
| `notes.md` | 你的会议笔记（有内容时才生成） |
| `translation-<语言>.md` | 生成的译文（如 `translation-zh.md`） |
| `session.json` | 会话元数据：标题、编号、时长、转写服务与模型、译文语言、分片数 |

`audio.wav` 只在音频还在时生成；音频已删除的会话导出会跳过它，但转写和笔记照常导出。

## 音频保留策略

应用支持「保留音频」和「转写后删除音频」两种保留策略，这个选择会被记住。选了转写后删除音频之后：

- 转写成功时，或停止录音时已经积累了实时字幕，才会删除音频分片。
- 转写、笔记和恢复清单元数据都会保留。
- 转写覆盖不足时不会删，会提示「转写覆盖不足 90%，已保留音频；请重新转写后再删除」。

手动删除随时可用：在完成页的「更多」菜单里点「删除音频」，会二次确认「删除后音频不可恢复，转写和会议笔记会保留」。

删除后，历史库里这条会话仍保留，状态标记为**仅转写**，你仍然可以查看和导出转写与笔记，只是不能再回放音频。

## 容量视图与清理

「设置 → 录音资料库」（也就是历史录音面板）底部能看到占用统计：总会话数、音频占用、总占用，以及多少条是仅转写。

两种清理方式：

- **按时间清理**：选「30 天前 / 90 天前 / 180 天前」，点「清理旧音频」。只清理已有转写且转写完整的会话的音频，转写与笔记保留。
- **按容量清理**：在「存储上限」里选 5 GB / 10 GB / 20 GB，超出后从最旧的会话开始删音频，转写保留。

另外「自动清理」可以设 30 / 90 / 180 天，在**下次启动**时清理对应时间之前的音频；「存储上限」同样下次启动生效。这两个设置留空或选「关闭 / 不限制」就不会自动清理。

## 删除整条会话

历史库每条记录右侧有删除按钮，会把整个会话目录**移入 Windows 回收站**，误删了可以还原。
