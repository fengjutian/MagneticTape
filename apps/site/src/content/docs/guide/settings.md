顶部导航的「设置」按钮打开设置面板，里面分三块：**AI 服务**、**转写服务**、**录音资料库**。面板底部写明：所有设置保存在本机，API Key 加密保存在 Windows 凭据管理器。

## 录音控制栏里的配置

这些选项直接改当前录音会话的行为，改完立即生效并记住。

| 选项 | 可选值 | 说明 |
|---|---|---|
| 转写语言 | 自动识别 / 中文 / English | 传给转写服务的识别语言 |
| AI 同传 | 不翻译 / 实时翻译为中文 / Live English translation | 录音中的增量翻译目标语言 |
| 麦克风 | 设备列表 | 采集人声，默认选系统的默认麦克风 |
| 系统声音 | 设备列表 | 采集电脑播放的声音，默认选默认输出设备 |
| 实时字幕 | 开 / 关 | 是否在录音时生成实时字幕 |
| 录音场景 | 会议 / 学习 / 灵感 / 访谈 / 电话记录 / 自由录音 | 影响 AI 分析的结构 |

「重新检测设备」会在设备插拔后刷新列表。设备掉线时采集流会自动重建并提示重连状态。

## 转写服务

「设置 → 转写服务」打开「配置转写服务」对话框。

**服务商**（单选）：

- `本地 Whisper（离线）`：whisper.cpp 在本机推理，不需要 API Key 和网络。
- `OpenAI Realtime（流式）`、`MiniMax（分片）`、`SiliconFlow（分片）`：云端 ASR，音频会上传。

**识别语言**：自动识别 / 中文 / English。

**热词 / 提示词（可选）**：最多 512 字符，本地 Whisper 会作为初始提示词传入，云端服务商走提示字段。

**接口地址 / 模型 / API Key**：仅云端服务商需要。API Key 留空则复用已保存的密钥，「清除密钥」会删除凭据管理器里的条目。MiniMax 的 ASR 会复用 AI 助手的密钥。

**本地 Whisper 区块**（选择本地时显示）：模型下拉（Tiny / Base / Small / Large v3 Turbo）、热词、引擎与 GPU 状态、占用空间，以及四个按钮——「下载 CPU 引擎」「下载 CUDA 引擎」「下载模型」「删除模型」。CUDA 引擎只在检测到 NVIDIA GPU 时可下载。

**本地流式实时字幕区块**：

- 勾选框「本地流式实时字幕」控制是否优先走本地流式引擎，默认勾选。
- 四个下载按钮：流式引擎（24 MB）、中文流式模型（74 MB）、声纹模型（28 MB）、分离模型（7 MB）。已安装的按钮会自动隐藏。
- 状态行显示引擎版本、模型占用和是否「流式字幕已就绪」。

## AI 服务

「设置 → AI 服务」打开「配置 AI 助手」对话框。

- **服务商**：MiniMax 或 DeepSeek。默认模型分别是 `MiniMax-M3.1-Flash` 和 `deepseek-flash`，切换服务商时自动填入。
- **模型**：可改成服务商支持的其他模型。
- **API Key**：加密存进 Windows 凭据管理器，只发给你选的服务商。
- 「保存并测试连接」会保存并立刻发一次测试请求。
- 「清除密钥」删除凭据。

## 录音资料库

「设置 → 录音资料库」打开历史录音面板，底部有存储与诊断设置：

| 设置 | 可选值 | 生效时机 |
|---|---|---|
| 自动清理 | 关闭 / 30 天 / 90 天 / 180 天 | 下次启动 |
| 存储上限 | 不限制 / 5 GB / 10 GB / 20 GB | 下次启动 |
| 清理旧音频 | 30 天前 / 90 天前 / 180 天前 + 按钮 | 点按钮立即执行 |

自动清理和存储上限只在启动时跑一次：前者删掉指定天数之前的音频，后者从最旧的会话开始删音频直到落回上限内。两者都只删音频，转写保留。

「打开日志目录」打开本地日志文件夹，「导出诊断包」生成一份 zip。诊断包只含系统信息和日志/崩溃文件，**不含音频、密钥和转写正文**。

## 快捷键

| 快捷键 | 作用 |
|---|---|
| `空格` | 录音中暂停 / 恢复 |
| `Ctrl + Enter` | 录音中结束并保存 |
| `Alt + 1`–`5` | 切换转录 / 翻译 / AI 分析 / 任务 / AI 对话页签 |
| `Ctrl + Shift + I` | 展开或收起 AI 洞察栏 |
