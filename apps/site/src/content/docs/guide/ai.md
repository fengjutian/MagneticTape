title: AI 能力
description: 配置 AI 服务的密钥保存方式，以及 AI 同传、翻译、会议纪要和 AI 对话怎么用。
---

AI 能力分两块：**AI 同传 / 翻译 / 会议纪要 / AI 对话**需要接云端大模型，**AI 洞察**在本地从转写和笔记里提炼。

## 先配置 AI 服务

「设置 → AI 服务」里选服务商（MiniMax 或 DeepSeek）、填模型名和 API Key，点「保存并测试连接」确认能通。

- API Key 由 **Windows 凭据管理器**加密保存，不写进普通配置文件，也不出现在日志或诊断包里。
- 密钥只发给你选中的那一家服务商。
- 「清除密钥」会删除凭据管理器里的对应条目。

## AI 同传（录音中）

在「语音配置 → AI 同传」里选目标语言（不翻译 / 实时翻译为中文 / Live English translation）。录音中每产生一段新的实时字幕，应用就增量送一次翻译，译文按段显示在原文旁边。

翻译失败不会影响录音和 ASR：字幕区会提示「AI 同传将在稍后重试」，录音照常进行，稍后自动接着翻。

## AI 翻译（录后）

转写完成后，在完成页选目标语言点「AI 翻译」。长转写会按行分块请求再合并，不会因为一次发太多被截断。译文以 `translation-<语言>.md` 保存，重新打开会话或导出时会直接复用。

## AI 会议纪要

「AI 分析」页签里有「会议笔记」编辑器和「AI 生成纪要」按钮：

1. 选择 AI 服务商（MiniMax / DeepSeek）。
2. 点「AI 生成纪要」，应用会基于你的笔记或本次转写生成 Markdown 纪要。
3. 生成结果会直接写进会议笔记，点「保存笔记」持久化到本地。

纪要采用**分片提取 + 归并**的方式：先把长会议切成片段分别提炼要点，再合并成一份完整纪要。因此长会议不会被单次输入或输出上限截断。纪要要求包含会议主题、核心结论、讨论要点、待办事项、风险与未决问题；原文没有的信息不会被编造。

## AI 洞察与复盘

右侧「AI 洞察」栏在录音过程中持续更新，展示当前主题、关键观点、决策事项、争议与分歧、待办事项和待确认问题。转写完成后点「进入复盘」可以看到完整转录、关键观点、决策记录和待办。

AI 生成的内容默认标记为「待确认」，在复盘页你可以逐条**确认、编辑或忽略**，确认后才会进入正式会议记录。点「全部确认…」可以一次处理。

## AI 对话

「AI 对话」页签基于当前录音的转写内容回答问题，回答会引用原始片段。直接输入问题，或点下方的示例问题。前提是已经配置好至少一个可用的 AI 服务商，否则会提示先去「设置 → AI 服务」配置 MiniMax 或 DeepSeek 的 API Key。
