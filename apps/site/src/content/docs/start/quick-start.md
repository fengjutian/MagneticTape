---
title: 快速开始
description: 从启动到拿到第一份会议纪要的完整流程：选设备、开录音、实时字幕、转写与导出。
---

MagneticTape 的工作台分三栏：**左侧录音控制**、**中间实时转录**、**右侧 AI 洞察**。下面按顺序走一遍完整流程。

## 1. 给这次录音起个名字

界面左上角的「新录音」标题可以直接点击编辑（最多 80 字）。标题会成为历史记录和导出目录的名字，建议在开会前就写好「2026-11-09 产品评审」这类可检索的名字。

## 2. 选择录音场景

「录音场景」提供六个预设，它们只影响 AI 分析的结构，不影响录音本身：

| 场景 | 用途 |
| --- | --- |
| 会议 | 多人讨论、纪要 |
| 学习 | 课程、讲座 |
| 灵感 | 个人语音记录 |
| 访谈 | 一对多问答 |
| 电话记录 | 通话纪要 |
| 自由录音 | 不做结构假设 |

## 3. 确认音频设备

展开左栏的「音频配置」，分别选择**麦克风**和**系统声音**设备：

- **麦克风**采集你本人和现场的人声；
- **系统声音**采集电脑播放的内容（远程会议对方的声音通常走这一路）。

设备列表下方是实时电平，说话或放音时应该能看到电平跳动。设备不对时点「重新检测设备」。

:::tip
设备掉线、休眠唤醒或音频服务重启后，应用会自动重建采集流，并在页面上提示重连状态，不需要手动重启。
:::

## 4. 设定语音与 AI 选项

- **语音配置 → 转写语言**：自动识别 / 中文 / English。
- **语音配置 → AI 同传**：不翻译 / 实时翻译为中文 / Live English translation。开启后会在右侧按段显示原文与译文。
- **AI 配置 → 实时字幕**：开关。打开前需要先在「配置转写服务」里下载本地流式引擎与中文流式模型（见[字幕与转写](/guide/transcription/)）。

## 5. 开始录音

点击「开始录音」。状态卡会显示录音中状态、计时和已写入的分片数，右侧实时出现字幕。

录音过程中可以随时暂停与恢复，麦克风和系统声音都按同一时间轴记录，恢复后继续对齐。

## 6. 结束后：转写与纪要

停止录音后进入完成页：

1. 点「转写」生成定稿文本。选的是**本地 Whisper** 时全程离线；选云端服务时会提示音频会上传。
2. 点「生成纪要」，AI 会把长会议按分片提取再归并成结构化纪要，并自动写入会话笔记。
3. 需要其他语言时点「翻译」，译文会保存下来，之后重新打开会话或导出时直接复用。

## 7. 回放与导出

中间栏「转录」页签可以点时间戳跳转到对应位置，并高亮当前句；回放支持拖动进度和 0.75–2× 倍速。

点「导出会议资料」会在 `文档/MagneticTape/<标题>-<会话编号>/` 下生成会议文档、字幕文件、混音 WAV 与元数据，详见[导出与整理](/guide/export/)。
