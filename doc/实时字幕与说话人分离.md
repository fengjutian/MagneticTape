# 实时字幕与说话人分离

> 状态：代码已实现（流式字幕 + 在线声纹 + 离线分离），构建与单元测试通过；真机模型下载与运行验证待做。

## 1. 实现方式

| 能力 | 实现 | 位置 |
|---|---|---|
| 流式字幕 | sherpa-onnx `OnlineRecognizer`（中文 Zipformer 14M） | `apps/desktop/src-tauri/src/sherpa.rs` |
| 引擎加载 | `LoadLibraryExW` + `GetProcAddress` 手动绑定，无 libclang / C 工具链依赖 | `sherpa.rs` |
| 在线说话人 | campplus 中文声纹 + 余弦聚类（阈值 0.65，最多 8 人） | `SpeakerEngine` / `SpeakerGallery` |
| 离线说话人 | pyannote-3.0 INT8 分割 + campplus + 聚类（阈值 0.7） | `diarize()` |
| 音频输入 | 复用 `drain_realtime_pcm()` 的 24 kHz 混音 PCM，sherpa 内部重采样到 16 kHz | `lib.rs` `poll_live_inner` |
| 标签合并 | 文本片段中点落在哪个说话人区间就归谁 | `assign_speakers()` |
| 标签延续 | 重新转写时按时间重叠把旧标签带到新片段 | `carry_over_speakers()` |

录音仍按原有 5 秒 Ogg Opus 分片落盘，流式识别与录音写盘互不影响；分片只是不再用于实时字幕。

## 2. 模型与空间

| 组件 | 大小 | 下载时机 |
|---|---|---|
| sherpa-onnx 1.12.9 win-x64 shared | 24.1 MB | 设置页手动 |
| 中文流式 Zipformer 14M | 74.0 MB | 设置页手动 |
| campplus 中文声纹 | 28.3 MB | 设置页手动 |
| pyannote-3.0 分割（INT8） | 7.0 MB | 设置页手动 |

保存位置：`%APPDATA%\com.magnetictape.desktop\sherpa\`。

- `engine/`：解压后把 `lib/` 下所有 DLL 摊平，保证 `onnxruntime.dll` 与 `sherpa-onnx-c-api.dll` 同目录。
- `models/zh-14m/`：流式 ASR 模型。
- `models/3dspeaker_campplus_zh_cn.onnx`：声纹。
- `models/pyannote-3.0/`：离线分割模型。

## 3. 使用

1. 打开「转写服务」对话框。
2. 在「本地流式实时字幕」区域依次下载：流式引擎 → 中文流式模型 →（可选）声纹模型 →（可选）分离模型。
3. 保持「本地流式实时字幕」勾选。
4. 开始录音并打开左侧「实时字幕」开关。

字幕延迟：首字约 0.3–0.5 秒，整句在停顿约 0.8 秒后定稿。语音片段结束时自动做一次声纹聚类，同一人被归到同一个 `S1/S2/...`。

录后转写时：

- 已安装分离模型 → 用 pyannote 全量重跑，结果比在线声纹更准，覆盖在线标签。
- 未安装分离模型 → 保留在线标签，并通过中点重叠延续到新转写。
- 都没有 → 显示「发言人」，不再按行号编 A/B/C/D。

## 4. 参数

| 参数 | 值 | 说明 |
|---|---|---|
| endpoint rule2 | 0.8 s | 说话后静音多久算一句结束，越小越快、越易切碎 |
| endpoint rule3 | 20 s | 单句上限，防止一直不断句 |
| 在线聚类阈值 | 0.65 | 越小越容易合并，越大越容易多分人 |
| 离线聚类阈值 | 0.7 | DIAR-1 spike 在四人中文样例上的最优值 |
| 离线最短语音 | 0.3 s | 短于此的片段丢弃 |
| 单次离线分离上限 | 2 小时 | 16 kHz f32 约 460 MB，超过后保留在线标签 |

## 5. 已知限制

- **重叠说话**：在线声纹按“一句一个 embedding”归类，两人同时说话时不可靠；离线分离对重叠也只做区间切分。
- **远场/混响**：真实双人会议尚未按 85% 验收线验证（DIAR-1 遗留项）。
- **模型校验**：引擎包固定了 SHA-256；三个模型在 GitHub 发布页没有提供逐文件摘要，目前只校验字节数 + HTTPS。
- **平台**：流式引擎目前只支持 Windows x64（`LoadLibraryExW`）。
- **长录音**：单次离线分离上限 2 小时。
