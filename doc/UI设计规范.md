# MagneticTape UI 设计规范

本规范适用于桌面端所有页面、弹窗和交互状态。新增或修改 UI 时必须遵守；若实现与规范冲突，应先更新规范并说明原因。

## 1. 品牌主题

MagneticTape 使用绿色作为唯一品牌主题色。绿色表达本地、安全、稳定录制，不使用蓝色或紫色作为主按钮、选中态、焦点态或品牌图标颜色。

| 令牌 | 色值 | 用途 |
|---|---|---|
| `--ui-primary` | `#18A66A` | 主按钮、选中态、活动图标、进度 |
| `--ui-primary-hover` | `#128456` | 悬停、按下、深色文字 |
| `--ui-primary-soft` | `#E9F8F0` | 浅色按钮、图标底座、选中背景 |
| `--ui-text` | `#171A2B` | 标题和主要文字 |
| `--ui-muted` | `#747B91` | 辅助说明和次要信息 |
| `--ui-border` | `#E5E7EF` | 卡片与控件边界 |

品牌色必须通过 CSS 自定义属性引用。禁止在组件样式中新增重复的品牌色十六进制值；透明效果使用 `rgba(24, 166, 106, alpha)`。

## 2. 语义色

- 红色：录音警示、错误、删除等危险操作。
- 橙色：需要用户关注但不阻断流程的警告。
- 绿色：成功、安全、活动状态和所有品牌交互。
- 蓝色：只用于无法用品牌色表达的信息语义，不得用于主操作或品牌装饰。
- 灰色：禁用、待机和辅助信息。

颜色不能作为唯一状态提示；必须同时提供文字、图标或形状变化。

## 3. 图标

- 统一使用项目已引入的 Lucide 图标库，不新增风格不一致的手绘 SVG。
- 常规图标使用 `16–20 px`，主视觉图标使用 `20–28 px`，线宽保持 Lucide 默认视觉风格。
- 带文字的按钮使用“图标在左、文字在右”；纯图标按钮必须提供 `title` 和可访问名称。
- 同一操作在不同页面使用相同图标，不使用图标代替难以理解的业务文案。

## 4. 组件与层级

- 主按钮：绿色实底、白色文字；一个操作区域原则上只出现一个主按钮。
- 次按钮：浅绿色底或中性灰底；危险按钮使用浅红底或红色文字。
- 卡片：优先使用浅边框区分层级，阴影保持轻量；避免多层高强度阴影。
- 圆角：普通控件 `8–10 px`，功能卡片 `12–16 px`，主面板 `20–24 px`。
- 聚焦环统一使用半透明绿色，并满足键盘操作可见性要求。

## 5. 录音状态

- 待机：中性背景配绿色主操作。
- 录音中：绿色为主要活动色，红色只用于“录音中”警示点或停止操作。
- 暂停：降低波形与活动区域饱和度，保留清晰的继续入口。
- 完成：使用绿色成功状态，导出仍为绿色主操作。
- 错误：使用红色提示，同时保留可恢复操作。

## 6. 验收检查

提交 UI 变更前至少确认：

1. 主操作、选中态和品牌图标均使用绿色主题令牌。
2. 页面不存在无语义的蓝色或紫色品牌元素。
3. 图标来自 Lucide，尺寸和排列一致。
4. 键盘焦点清晰，文字与背景满足 WCAG AA 对比度。
5. `npm run build` 通过，录音状态和事件选择器未被破坏。
