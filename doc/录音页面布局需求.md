# MagneticTape 录音页面布局需求

> 状态：已实现（双路本地音频采集及周期 WAV checkpoint 已接入，ASR 尚未接入）  
> 参考：飞书妙记 Windows 录音页  
> 适用范围：`apps/desktop` Tauri 桌面端  
> 更新日期：2026-11-05

## 1. 背景与目标

当前桌面端为单栏演示页面，无法同时承载录音控制、实时转写和录音后的内容整理。本次将录音页调整为类似飞书妙记的双栏工作台：左侧集中展示会话信息、录音状态和控制，右侧承载实时字幕及后续内容。

本需求参考飞书妙记的信息层级和空间关系，不要求逐像素复制其品牌元素、图标或文案。页面应保持 MagneticTape 的产品命名，并为后续真实音频采集、ASR、翻译和 AI 总结预留稳定的组件区域。

## 2. 本期范围

### 2.1 包含

- 录音页双栏布局及桌面窗口自适应。
- 会话标题和录音选项工具栏。
- 左栏空字幕提示、实时音量波形、计时、暂停/继续和停止控制。
- 右栏内容面板及录音不同阶段的占位状态。
- 空闲、录音中、已暂停和正在结束四种界面状态。
- 键盘操作、焦点样式和基础无障碍语义。

### 2.2 不包含

- WASAPI 麦克风或系统音频采集实现。
- 实时转写、翻译、AI 总结及云服务接入。
- 历史录音列表、账号、权限、计费和分享能力。
- 对飞书图标、字体、商标或文案的直接复制。

上述未接入能力在本期使用禁用态、静态占位或模拟状态呈现。

## 3. 页面信息架构

```text
录音窗口
├── 左侧录音区
│   ├── 会话标题
│   ├── 录音选项工具栏
│   │   ├── 转写语言
│   │   ├── 翻译设置
│   │   ├── 音频保留设置
│   │   └── AI 同传入口（预留）
│   ├── 字幕/状态区
│   └── 底部录音控制区
│       ├── 音量波形
│       ├── 已录时长
│       ├── 暂停/继续
│       └── 停止
└── 右侧内容区
    ├── 实时字幕（录音中）
    └── 录音结果/摘要（结束后，预留）
```

## 4. 布局要求

### 4.1 窗口

- 默认窗口建议尺寸为 `1220 × 900 px`，最小尺寸为 `960 × 640 px`。
- 页面占满客户端区域，不出现整页滚动条；需要滚动的内容仅在左右面板内部滚动。
- 页面背景使用接近白色的中性色，左右区域之间通过留白和面板层级区分，不使用粗分割线。
- 使用 Windows 原生窗口标题栏时，内容从标题栏下方开始；若后续采用自定义标题栏，拖拽区和窗口按钮不得覆盖页面交互控件。

### 4.2 双栏关系

- 页面采用左窄右宽的双栏结构。
- 左栏默认宽度约占窗口的 `46%`，建议限制在 `440–560 px`。
- 右栏占据剩余空间，最小宽度为 `420 px`。
- 两栏间距为 `16 px`；页面外边距建议为左侧 `48–60 px`、上方 `36–48 px`、右侧及下方 `8–16 px`。
- 右栏为独立白色卡片，圆角 `12–16 px`，使用极浅描边或柔和阴影建立层级。
- 本期不要求支持拖拽改变左右栏宽度。

### 4.3 小窗口适配

- 当窗口宽度低于 `960 px` 时仍保持双栏，压缩页面外边距及左栏宽度。
- 不允许标题、计时和录音主按钮因宽度不足相互覆盖。
- 当实际可用宽度不足以满足最小尺寸时，允许窗口系统阻止继续缩小，不切换为移动端单栏布局。

## 5. 左侧录音区

### 5.1 会话标题

- 位于左栏顶部，默认名称为“新录音”。
- 同一天内新建录音可追加自然序号，如“新录音 2”。
- 标题字号建议为 `28–32 px`，字重 `500–600`，颜色为深灰黑。
- 点击标题进入编辑态；按 `Enter` 或失焦保存，按 `Esc` 取消。
- 标题为空时恢复默认名称；显示长度超过一行时截断，编辑态可查看完整内容。

### 5.2 录音选项工具栏

- 位于标题下方 `18–24 px`，横向排列，项目间距 `24–32 px`。
- 项目由图标、短文案和可选下拉箭头组成，视觉权重低于标题和录音控制。
- 首期显示以下项目：

| 项目 | 默认文案 | 本期行为 |
|---|---|---|
| 转写语言 | 自动识别 | 可打开菜单；未接入时仅切换前端选项 |
| 翻译 | 不翻译 | 可打开菜单；未接入时仅切换前端选项 |
| 音频 | 保留音频 | 可打开菜单；用于表达本地保存策略 |
| AI 同传 | AI 同传 | 禁用或标记“即将支持” |

- 禁用项必须保持可读，并通过 `disabled` 语义及提示说明不可用原因。
- 工具栏在空间不足时允许换行，但不得覆盖标题或右侧面板。

### 5.3 字幕/状态区

- 占据左栏中部剩余高度，内容水平居中，垂直位置约在可用区域中心略偏上。
- 未产生字幕时显示：“实时转写功能尚未接入，录音仍会保存在本地。”
- 文案使用 `14–16 px` 次要文字色，最大宽度 `320 px`，居中对齐。
- 录音暂停时增加明确的“录音已暂停”状态，不依赖颜色单独传达。
- 后续接入实时字幕后，此区域切换为可滚动字幕流，最新内容靠近底部，用户手动上滚时不得强制抢回滚动位置。

### 5.4 底部录音控制区

- 固定在左栏底部，不随字幕内容滚动。
- 控制区由波形和操作行两部分组成，与窗口底部保留 `24–32 px` 安全间距。

#### 波形

- 横向占据左栏可用宽度，建议高度 `24–32 px`。
- 由等间距竖条组成，圆角端点，颜色使用中性灰；录音中可根据模拟或真实音量改变高度。
- 暂停时停止动态并降低对比度；空闲或结束处理中显示静态波形。
- 尊重系统“减少动态效果”设置，禁用持续脉冲或高频动画。

#### 操作行

- 左侧显示累计时长，格式为 `MM:SS`；超过一小时后显示 `HH:MM:SS`。
- 中间为暂停/继续主控制，使用蓝色浅底胶囊按钮，建议尺寸 `102 × 54 px`。
- 右侧为停止按钮，使用中性浅灰底胶囊按钮，建议尺寸 `84 × 48 px`。
- 暂停和停止图标均需提供可访问名称及悬浮提示。
- 操作行三部分在视觉上均匀分布，主控制按钮优先保持居中。

## 6. 右侧内容区

- 右侧面板从页面顶部内容区开始并延伸至底部，形成稳定的内容容器。
- 空闲时显示简洁占位说明，引导用户开始录音。
- 录音中用于显示实时字幕；未接入 ASR 时显示骨架占位或明确的未接入说明，不伪造转写结果。
- 暂停时保留已有内容，并在面板顶部显示暂停状态。
- 停止后预留“转写内容 / 摘要”结构；本期可展示会话已保存的信息与本地文件状态。
- 面板内边距建议为 `28–36 px`，内容区域可独立纵向滚动。

## 7. 页面状态与交互

| 状态 | 计时 | 波形 | 暂停按钮 | 停止按钮 | 主要提示 |
|---|---|---|---|---|---|
| 空闲 | `00:00` | 静态 | 禁用 | 禁用 | 等待开始录音 |
| 录音中 | 持续增加 | 动态 | 显示暂停，可用 | 可用 | 正在录音 |
| 已暂停 | 保持不变 | 静止 | 显示继续，可用 | 可用 | 录音已暂停 |
| 正在结束 | 保持不变 | 静止 | 禁用 | 加载态、禁用 | 正在保存录音 |

- 若当前应用入口仍使用“开始记录”按钮，开始后应切换到本需求定义的录音工作台状态。
- 点击停止需进入“正在结束”，后端确认停止成功后再展示完成状态，避免重复提交。
- 后端命令失败时恢复到可操作状态，并在页面内显示错误信息；不得只写入控制台。
- 所有按钮在执行异步命令期间防止重复点击。

## 8. 视觉规范

- 字体优先使用 Windows 系统 UI 字体栈，不额外下载飞书字体。
- 主文字建议 `#1F2329`，次要文字建议 `#8F959E`，弱提示建议 `#B8BDC6`。
- 主交互色使用项目蓝色，建议以 `#3370FF` 为基准；浅色按钮背景建议 `#E8EEFF`。
- 页面背景建议 `#F7F8FA`，内容面板背景为 `#FFFFFF`。
- 控件圆角保持统一：普通按钮 `8–10 px`，胶囊按钮使用高度的一半，内容面板 `12–16 px`。
- 阴影应轻量，避免厚重悬浮感；边框与阴影至少选择一种提供边界识别。
- 图标使用项目自有 SVG 或开源图标集，并保持统一的 `16–20 px` 线性风格。

## 9. 可访问性与键盘操作

- 所有交互元素必须可通过 `Tab` 聚焦，并具有清晰可见的焦点环。
- 下拉菜单支持方向键移动、`Enter` 选择和 `Esc` 关闭。
- 暂停/继续与停止按钮必须使用原生 `button` 元素，不使用仅带点击事件的 `div`。
- 动态状态通过 `aria-live="polite"` 播报，但计时器每秒变化不应持续打扰读屏用户。
- 文本与背景对比度应达到 WCAG AA；禁用态仍需保证文案可辨认。
- 建议快捷键：`Space` 暂停/继续，`Ctrl+Enter` 停止。输入框获得焦点时不得触发页面快捷键。

## 10. 数据与组件边界

建议前端使用单一页面状态模型，避免各组件自行推断录音状态：

```ts
type RecorderStatus = "idle" | "recording" | "paused" | "stopping" | "finished" | "error";

interface RecorderViewState {
  title: string;
  status: RecorderStatus;
  elapsedSeconds: number;
  language: string;
  translation: string | null;
  retainAudio: boolean;
  volumeLevel: number;
  errorMessage?: string;
}
```

建议拆分为标题、选项工具栏、字幕状态区、波形、录音控制条和右侧内容面板六个独立视图组件。组件只通过状态和事件通信，不直接调用 Tauri 命令；命令调用统一由页面控制器处理。

## 11. 验收标准

1. 在 `1220 × 900 px` 窗口下，页面呈现左窄右宽双栏，右栏卡片与截图的空间关系基本一致。
2. 在最小窗口尺寸下，无控件重叠、不可见或整页滚动；左右内容区可独立工作。
3. 标题可编辑，四个工具栏项目均有明确的可用或禁用状态。
4. 空闲、录音中、已暂停和正在结束状态的计时、波形、按钮和提示符合状态表。
5. 暂停/继续和停止操作具有防重复提交机制，错误可在页面内被用户看到。
6. 波形区域在录音中有可见反馈，暂停后立即静止；减少动态效果开启时无持续动画。
7. 页面所有操作可仅使用键盘完成，焦点顺序与视觉顺序一致。
8. 不使用飞书商标、专有字体或直接复制的品牌素材。
9. `npm run build` 通过，现有 Rust 测试和前端状态流程不因布局调整而失效。
