# 视觉风格 v7：极光玻璃（Aurora Glass）

> 状态：设计定稿，随本次 UI 改造落地  
> 适用范围：`apps/desktop` Tauri 桌面端所有页面、弹窗与状态  
> 设计来源：用户提供的参考图（玻璃卡片 + 极光渐变 + 粉彩标签），非逐像素复刻  
> 关联规范：[UI 设计规范](UI设计规范.md)、[录音页面布局需求](录音页面布局需求.md)

## 1. 定位

MagneticTape 是**本地录音工具**，不是作品集页面。参考图贡献的是三样东西：

1. **氛围**：极光渐变背景 + 点阵纹理，让界面有“空间”而不是一张白纸。
2. **材质**：半透明白玻璃、柔和阴影、内高光，替代原先“白上白 + 1px 边框”的层级方式。
3. **色彩节奏**：低饱和粉彩块负责节奏，高饱和色只留给真正的操作与状态。

**不借**：参考图的展示型大字号（40px 级标题）、55% 透明度的正文底板、照片式 hero、装饰性英文标签。

一句话原则：**外壳像参考图，内容像工具。**

## 2. 四条硬规则

| # | 规则 | 原因 |
|---|---|---|
| R1 | 层级靠“光”，不靠“线”：阴影 + 内高光 + 玻璃明度差 ≥ 8% | 现状三块白色明度差不足 5%，只能靠边框撑层级，所以发平 |
| R2 | 玻璃只做外壳：最多两层 `backdrop-filter`（工作区背景 + 两块主面板），内层控件一律实色/半实色，不叠模糊 | WebView2 下大面积模糊有 GPU 成本，嵌套模糊会糊字 |
| R3 | 颜色表达能力域：**绿 = 本地/录制/安全/成功；Iris（紫）= AI/转写/翻译/生成**；红 = 错误；琥珀 = 暂停 | 保留“本地安全”的绿色识别，同时让 AI 能力有独立可识别的颜色 |
| R4 | 可读性红线：正文落在 ≥ 85% 白的等效底上；微标签 ≥ 10.5px 且对比度 ≥ 4.5:1；禁止把 13px 正文直接放在 55% 玻璃上 | 参考图按展示尺寸调色，桌面工具窗口更小、密度更高 |

## 3. 色彩系统

### 3.1 主色（绿 · 本地与录制）

| 令牌 | 色值 | 用途 |
|---|---|---|
| `--ui-primary` | `#128456` | 开始录音、暂停态、进度、本地文件强调 |
| `--ui-primary-hover` | `#0C6B44` | 悬停/按下 |
| `--ui-primary-soft` | `#E6F6EF` | 浅底按钮、图标底座、活动背景 |
| `--ui-primary-line` | `rgba(18, 132, 86, .24)` | 描边、聚焦环 |

> 相比旧规范 `#18A66A`，主色加深到 `#128456` 以满足白字按钮的 4.5:1 对比度（旧值约 4.3:1，处于临界）。

### 3.2 第二语义色（Iris · AI 能力）

| 令牌 | 色值 | 用途 |
|---|---|---|
| `--ui-iris` | `#6C5CE7` | AI 主操作：开始转写、AI 生成纪要、发送 |
| `--ui-iris-hover` | `#5A4BD1` | 悬停/按下 |
| `--ui-iris-soft` | `#EFEBFE` | AI 图标底座、AI 次级按钮、译文块背景 |
| `--ui-iris-ink` | `#4E3FC8` | AI 浅底上的文字 |
| `--ui-iris-line` | `rgba(108, 92, 231, .26)` | AI 描边/聚焦环 |

**使用边界**：Iris 只出现在“AI 参与”的入口与结果上（AI 同传、AI 助手、实时字幕、转写、翻译、AI 纪要）。录音、设备、本地文件、导出、播放一律使用绿色或中性色。禁止用 Iris 做页面主按钮、选中态、导航选中或品牌图标。

### 3.3 中性色与画布

| 令牌 | 色值 | 用途 |
|---|---|---|
| `--ui-ink` | `#232338` | 标题与正文 |
| `--ui-muted` | `#646A7E` | 次要说明（白底 5.6:1） |
| `--ui-faint` | `#8A8FA2` | 占位、禁用、装饰（不承载关键信息） |
| `--ui-line` | `rgba(84, 90, 126, .12)` | 常规分隔线 |
| `--ui-line-strong` | `rgba(84, 90, 126, .20)` | 需要强调的边界 |
| `--ui-canvas` | `#F4F6FB` | 降级后的纯色底 |

### 3.4 极光画布

```css
background:
  radial-gradient(1100px 700px at 6% -8%, rgba(110, 231, 183, .38), transparent 62%),
  radial-gradient(900px 620px at 98% -6%, rgba(167, 155, 245, .30), transparent 60%),
  radial-gradient(900px 700px at 78% 108%, rgba(147, 197, 253, .28), transparent 62%),
  radial-gradient(700px 500px at 20% 105%, rgba(196, 181, 253, .18), transparent 60%),
  linear-gradient(135deg, #F7FBF9 0%, #F4F6FC 46%, #F7F3FD 100%);
```

叠加点阵（仅左上区域，用遮罩淡出）：`1px` 点、间距 `18px`、颜色 `rgba(76, 82, 120, .16)`。

约束：
- 饱和度控制在参考图的六成左右；背景不得比内容更抢眼。
- 点阵只出现在画布层，不进入面板内部。
- 面板透出背景即可，不做“彩色玻璃”。

### 3.5 状态色

| 状态 | 底色 | 文字 |
|---|---|---|
| 待机 | `#EEF0F6` | `#636A7E` |
| 录音中 | `#FFE8EA` | `#C33C45`（带 7px 红点） |
| 已暂停 | `#FFF3DC` | `#8A5A0B` |
| 已完成 | `#E4F7EC` | `#197A4C` |
| 错误 | `#FFE8EA` | `#B3262E` |

## 4. 材质与层级

三层结构，从上到下：

1. **画布层**：极光渐变 + 点阵。只负责氛围。
2. **外壳层**：两块主面板（录音区、内容区）。玻璃只在这一层使用。
3. **内容层**：选项卡、设备条、状态卡、转写行、表单。半实色底，不模糊。

```css
/* 外壳 */
border: 1px solid rgba(255, 255, 255, .72);
background: linear-gradient(160deg, rgba(255, 255, 255, .72), rgba(255, 255, 255, .54));
box-shadow:
  0 24px 60px rgba(64, 58, 112, .10),
  0 2px 8px rgba(64, 58, 112, .05),
  inset 0 1px 0 rgba(255, 255, 255, .85);
backdrop-filter: blur(24px) saturate(1.2);
```

| 层 | 底 | 描边 | 阴影 |
|---|---|---|---|
| 主面板 | 55–72% 白 + 24px 模糊 | `rgba(255,255,255,.72)` | 大而柔 + 内高光 |
| 功能卡 | `rgba(255,255,255,.66)` | `rgba(255,255,255,.7)` | `0 2px 8px rgba(64,58,112,.04)` |
| 下沉区 | `rgba(247,248,252,.78)` | `--ui-line` | 无 |
| 弹窗 | 92% 白 + 30px 模糊 | 白 | `0 30px 90px rgba(40,36,80,.22)` |

**降级**：`@supports not (backdrop-filter: blur(1px))` 时面板改为 `#FBFCFE`，阴影保留，层级仍然成立。

## 5. 形状与间距

| 令牌 | 值 | 用途 |
|---|---|---|
| `--ui-radius-panel` | `26px` | 录音面板、内容面板 |
| `--ui-radius-hero` | `20px` | 状态卡、弹窗内区块 |
| `--ui-radius-card` | `16px` | 选项卡、转写卡、空状态图标砖 |
| `--ui-radius-control` | `12px` | 按钮、输入框、下拉 |
| `--ui-radius-pill` | `999px` | 状态 pill、标签、主按钮可选胶囊 |

- 工作区外边距 `20px`，列间距 `18px`；面板内边距 `22–26px`。
- 间距基数 4；不要把任意值散落在组件里。
- 阴影只给外壳和可点击卡片；静态内卡不加悬浮阴影。

## 6. 字体

- 字体栈不变：`Segoe UI Variable / Segoe UI / Microsoft YaHei UI`。
- 标题 `26px / 650 / -0.02em`；面板标题 `22px / 650`；卡片标题 `14px / 650`。
- Kicker：`10.5px / 700 / 0.18em / uppercase`，颜色 `--ui-muted`。
- 正文 `13–14px / 1.65`；微标签最小 `10.5px`，禁止 9px 承信息。
- 时间与路径继续使用 `Cascadia Mono`，等宽对齐。
- 不使用展示型 40px 标题；窗口宽度 1220 时标题不得超过 28px。

## 7. 组件映射

| 组件 | v7 处理 |
|---|---|
| 工作区 | 极光画布 + 点阵；外边距 20，列间距 18 |
| 录音面板 / 内容面板 | 玻璃外壳：26px 圆角、白描边、大柔阴影、24px 模糊 |
| 会话标题 | 26px；本地 badge 为绿色 pill；历史录音为中性浅底 |
| 选项卡（语言/音频/AI 同传/AI 助手/实时字幕） | 16px 圆角半实色卡；AI 项图标底座用 Iris，其余用绿或中性 |
| 设备条 | 半实色下沉条；设备图标为绿色 soft 砖 |
| 状态卡 | 独立 hero：径向高光 + 薄荷/薰衣草微光；开始录音为绿色主按钮 |
| 录音控制 | 保持紧凑平铺；波形用绿色，暂停降饱和；倒计时用等宽 |
| 内容面板头部 | 图标砖 + kicker + 22px 标题 + 粉彩状态 pill |
| 转写行 | 16px 圆角卡片、白底、说话人粉彩 chip（薄荷/薰衣草/天蓝循环） |
| 实时译文 | Iris 左边线 + `--ui-iris-soft` 底，与浅绿区分 |
| AI 操作（转写/翻译/纪要/发送） | Iris 实底或 Iris 浅底；不使用渐变承载白字 |
| 本地操作（播放/导出/打开文件夹） | 绿色或中性 |
| 空状态 | 磨砂图标砖（64px，20px 圆角）+ 16px 标题 |
| 弹窗 | 92% 白 + 模糊；`::backdrop` 用 30% 深靛 + 6px 模糊 |

## 8. 动效

- 交互过渡 `150–200ms ease`；只做位移 1–2px、阴影和背景变化。
- 禁止常驻呼吸、闪光、渐变流动。
- `prefers-reduced-motion: reduce` 下移除位移动画与脉冲，仅保留状态切换。

## 9. 性能预算

- `backdrop-filter` 最多 2 个面板 + 1 个打开中的弹窗；内层一律禁用。
- 模糊半径 ≤ 26px；不使用 `filter: blur()` 叠加在滚动容器上。
- 转写列表超过 200 行时，避免每行都带阴影；用底边分隔线降级。
- 低配设备或远程桌面场景由 `@supports` 与 `prefers-reduced-transparency` 兜底。

## 10. 可访问性

- 正文与底色的对比度 ≥ 4.5:1；次要文字 ≥ 4.5:1；禁用态文字 ≥ 3:1。
- 焦点环统一 `0 0 0 3px rgba(18,132,86,.28)`；Iris 控件使用 `rgba(108,92,231,.30)`，均需在键盘下清晰可见。
- 颜色不是唯一状态提示：录音中必须同时有红点 + 文案，暂停必须有文案。
- 玻璃不得降低文字可读性；必要时在文字下加 85% 白 scrim。
- 尊重 `prefers-reduced-motion`。

## 11. 迁移与验收

验收清单：

1. 1220×900 与 960×640 下，双栏不重叠、不出现整页滚动。
2. 录音中 / 暂停 / 完成 / 错误四态的 pill、按钮、波形一致。
3. 绿色只出现在本地/录制/成功语义；紫色只出现在 AI 语义。
4. 正文对比度抽查通过（标题、说明、转写、时间、禁用态）。
5. 关闭 `backdrop-filter` 或强制降级后，层级仍可辨认。
6. `npm run build`、`npm test`、`npm run test:e2e` 通过。
7. 录制态帧率无明显下降（WebView2，1280×800 参考）。

## 12. 明确不做

- 不复制参考图的 40px 展示标题、英文占位文案、照片 hero。
- 不引入第三方字体、图标风格或外部图片资源。
- 不用紫色替换品牌绿、导航选中态或录音主操作。
- 不为“像参考图”而增加无意义的装饰层、光斑动画或悬浮 dock（导航改造另立需求）。
